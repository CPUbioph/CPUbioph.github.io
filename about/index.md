# 关于本站

**Learn in CPU** 是一个面向中国药科大学学生的学习资源整理平台，主要围绕生物制药及相关专业课程学习、科研入门工具和常用学习资源进行建设。

本站希望把分散在不同平台、不同群聊和不同文件夹中的学习资料进行集中整理，降低同学们重复查找资料的时间成本，让课程复习、实验报告、科研入门和工具学习变得更加清晰、有序。

## 建站初衷

​	在大学学习过程中，很多资料并不是难以获得，而是分散、重复、命名混乱，或缺少统一的整理入口。笔者初入大学深受其扰，考虑了多种方式后打算以网站形式进行资料的整理与分享 。

​	本站的建设目的不是替代课堂学习，而是作为一个辅助性的资料导航平台，帮助同学们更高效地找到已有资源，并在此基础上完成自主学习。

## 网站内容

本站目前主要包含以下几个部分：

### 课程资料

整理中国药科大学相关课程的学习资料，包括但不限于：

\- 课程课件

\- 复习资料

\- 历年题目

\- 实验课程资料

\- 教材与参考书目说明



资料主要用于课程学习与复习参考。部分内容可能来自同学整理、公开资料或课程学习过程中的积累，使用时请结合任课教师要求进行判断。

### 科研工具

整理学习和科研过程中常用的工具与入门教程，例如：

\- 文献检索工具

\- 文献管理软件

\- 科研绘图工具

\- Python / R 语言入门

\- Git 与 GitHub 使用

\- 数据库检索

\- AI 辅助学习与科研工具

###  资源推荐

收集常用学习网站、数据库、软件服务和课程辅助资源，帮助同学们减少搜索成本。 
优先整理实际学习中常用、稳定、对本科阶段有帮助的内容。

## 使用说明

1. 本站仅作为学习资源导航和资料整理平台，不保证所有资料完全覆盖课程考试范围。
2. 课程复习仍应以任课教师要求、课堂内容和学校教学安排为准。
3. 资料链接如来自百度网盘，建议使用百度网盘客户端下载，尤其是较大的 PDF、PPT 或压缩包文件。
4. 如发现链接失效、资料分类错误、文件命名不清或内容需要补充，可以通过反馈方式联系笔者。
5. 请勿将本站资料用于商业传播、付费售卖或其他不当用途。



##  资料来源与版权说明

本站资料主要用于同学之间的学习交流与资源整理。  
部分资料可能来源于课程学习过程、公开网络资源、同学整理或教师公开发布内容。

如果相关资料涉及版权、隐私或不适合公开展示，请联系笔者处理。本站将在核实后及时删除、替换或调整相关内容。

本站不鼓励未经授权的传播行为，也不支持将学习资料进行商业化使用。所有资料仅供个人学习、课程复习和学术训练参考。
